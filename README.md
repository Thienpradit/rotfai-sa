# รถไฟซ่า — เซิร์ฟเวอร์โหมดออนไลน์

เล่นได้ที่ **https://rotfai-sa.onrender.com**

เซิร์ฟเวอร์นี้ทำ 2 อย่างพร้อมกัน
1. เปิดหน้าเว็บเกม (`public/index.html`) ให้เพื่อนเข้ามาเล่นผ่านเบราว์เซอร์
2. ซิงก์โหมดออนไลน์ 2v2 ผ่าน WebSocket ที่ `/ws`

> ⚠️ โหมดออนไลน์ใช้ได้เฉพาะตอนเปิดเกมจากเซิร์ฟเวอร์นี้ ลิงก์เกมใน Claude เชื่อมต่อเซิร์ฟเวอร์ภายนอกไม่ได้

## รันบนเครื่องตัวเอง

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป (ดาวน์โหลดได้ที่ nodejs.org)

```bash
cd rotfai-server
npm install
npm start
```

จากนั้นเปิด `http://localhost:3000`
- เพื่อนที่ใช้ Wi-Fi วงเดียวกัน เข้าได้ที่ `http://<IP เครื่องคุณ>:3000`

## ขึ้นคลาวด์ Render (แนะนำ, ฟรี)

ใช้ไฟล์ `render.yaml` ที่เตรียมไว้แล้ว
1. สมัคร GitHub แล้วสร้าง repository ใหม่ (Public หรือ Private ก็ได้)
2. ใน repository กด **Add file → Upload files** แล้วลาก *ของข้างใน* โฟลเดอร์นี้ทั้งหมด (`server.js`, `package.json`, `render.yaml`, `README.md` และโฟลเดอร์ `public`) ขึ้นไป แล้วกด **Commit changes**
3. สมัคร render.com ด้วยบัญชี GitHub
4. กด **New → Blueprint** แล้วเลือก repository ที่เพิ่งสร้าง แล้วกด **Apply**
5. รอ build ประมาณ 2–3 นาที จะได้ลิงก์ในรูปแบบ `https://rotfai-sa.onrender.com` (ชื่ออาจต่างไปเล็กน้อย)

**ข้อจำกัดของแผนฟรี**
- ถ้าไม่มีคนเข้าเล่น 15 นาที เซิร์ฟเวอร์จะหลับ
- คนแรกที่เข้ามาหลังจากนั้นต้องรอประมาณ 1 นาทีให้เซิร์ฟเวอร์ตื่น
- ระหว่างที่กำลังเล่นกันอยู่ เซิร์ฟเวอร์จะไม่หลับ

**อัปเดตเกมภายหลัง:** อัปโหลด `public/index.html` ตัวใหม่ทับใน GitHub แล้ว Render จะ deploy ใหม่ให้อัตโนมัติ

## ขึ้นเซิร์ฟเวอร์จริง (ที่อื่น)

ใช้ได้กับทุกบริการที่รัน Node.js และรองรับ WebSocket เช่น Render, Railway, Fly.io หรือ VPS ทั่วไป

| ตั้งค่า | ค่า |
|---|---|
| Build command | `npm install` |
| Start command | `npm start` |
| Port | อ่านจากตัวแปร `PORT` อัตโนมัติ |

- ถ้าเว็บเป็น https เกมจะใช้ `wss://` ให้เองอัตโนมัติ
- บน VPS ที่มี Nginx อยู่ข้างหน้า ต้องเปิด WebSocket upgrade ให้ path `/ws` ด้วย

## 🤝 เล่นกับเพื่อน (เข้ามาจอยได้ตลอด)

1. กด **🤝 เล่นกับเพื่อน** แล้วกดเริ่มเล่น เล่นกับรถไฟ AI ได้เลยเหมือนเล่นคนเดียว
2. ในเกมกด **📤 ชวนเพื่อน** เพื่อส่งลิงก์ เพื่อนกดลิงก์แล้วเข้ามาเล่นในโลกเดียวกันได้ทันที (สูงสุด 8 คน)
3. เพื่อนชนกันไม่ตาย ระเบิด/แช่แข็งไม่โดนเพื่อน ตายแล้วเกิดใหม่ใน 3 วินาที · กด 🚪 ออก เมื่อเลิกเล่น

## ⚔️ ออนไลน์ 2v2

1. ทุกคนเปิดเว็บเกมจากเซิร์ฟเวอร์ของคุณ
2. กด **🌐 ออนไลน์ 2v2** แล้วใส่ **รหัสห้องเดียวกัน**
3. เลือกทีมเองได้ด้วยปุ่ม **เข้าทีมนี้** ใต้ทีมแดง/ทีมน้ำเงิน (ทีมละไม่เกิน 2 คน)
4. หัวหน้าห้อง 👑 กดเริ่มเกม

**กติกา**
- แข่งกัน 5 นาที
- ช่วง 2 นาทีสุดท้าย วงสนามจะหดลงเรื่อย ๆ
- คะแนนทีม = จำนวนที่กำจัดได้ × 100 + ความยาวรวมของทุกคนในทีมตอนหมดเวลา
- เพื่อนร่วมทีมชนกันไม่ตาย ระเบิด TGS และแช่แข็งก็ไม่โดนเพื่อนร่วมทีม
- ตายแล้วเกิดใหม่ได้หลัง 3 วินาที

## ตั้งค่าเพิ่มเติม (ตัวแปรสภาพแวดล้อม)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | 3000 | พอร์ตของเซิร์ฟเวอร์ |
| `MATCH_SECS` | 300 | ความยาวแมตช์ (วินาที) |

## อัปเดตตัวเกม

ถ้าได้ไฟล์เกม `index.html` เวอร์ชันใหม่ ให้เอาไปวางทับ `public/index.html` แล้วรีสตาร์ทเซิร์ฟเวอร์
